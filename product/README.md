装配整体包络保持220×120×145 mm。两个内胆独立封底，沿Z方向取出；前部留下净深30 mm的一个连通浅托盘，不再有中间隔断。没有螺丝、胶粘、卡扣或单独五金。
用户允许加厚，当前默认各件直壁/隔板3 mm、各件底板3 mm。内胆放在外托座3 mm底板上，所以笔格内部底面为装配z=6 mm。圆角平面外R5、内R3，口沿R0.8，底边倒角0.4 mm。

## 套装默认值与限制
- 外侧及背侧设计间隙0.5 mm；两个内胆之间0.8 mm。
- 内胆口沿高出相邻托座侧壁约12 mm，便于捏住取出；两件各自可独立上提。
- 外托座不做分格或前方止挡，内胆在前后方向可滑移。搬动整体时必须托住外托座，不靠抓内胆提起全套。
- 间隙和露出高度均是实现默认值，实际打印松紧和翘曲尚需样件检查。
- 左右内胆外宽按44:56分配；新增侧壁和分离间隙使有效收纳空间较一体版缩小。

## 验收与交付
三件各为有效连通实体；装配无实体穿透，内胆底与托座底面承托接触。最窄格≥12 mm，左宽格≥70×25 mm。保持15°前倾斜口与整体高度。检查装配视图、单独底座视图和内胆底面，最终导出包含三个独立对象的装配STEP。以导出记录的确切构建为交付版本。

## 制作与后续
默认PLA FDM原型，三件应各自平底朝下分开打印，不要把装配位置直接整体切片。未指定打印机、层高或支撑，不提供G-code；3MF排版是另行请求的阶段，需真实平台尺寸。无电子件，无PCB。
