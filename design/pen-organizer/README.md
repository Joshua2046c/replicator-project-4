# 三件式套层桌面笔筒

## Design intent
阶梯轮廓、15°前倾斜口、左右独立取出内胆。按user_front_wall_reference补齐前外壁；按user_transition_reference（product/references/uploads/20260923T111011740Z-1-mark.png）把前后高低交界改为两端圆滑的斜切过渡。后部共用腔不加左右隔板。原始风格、斜口和可拆参考为user_style_reference、user_slope_reference、user_removable_reference。整体220×120×145 mm，左最高90、右145。

## Geometry and interfaces
原点外底座底面中心，X右Y后Z上。organizer外包络220×120×133，底厚3、壁厚3，前托盘沿高15，左右后壁最高78/133。前壁外面y=-27、内面y=-24，前浅托盘净深30，后部共用腔214×81 mm；只有前壁将托盘和后腔分开，不做左右分格。外平面R5、内R3、口沿R0.8、底边倒角0.4。
前后外壁过渡均从x=-12.732至42.268，横向跨度55 mm，升高55 mm；两端轮廓圆弧R10与平台及中间直斜线相切。前后截面沿Y保留15°高度变化。过渡范围、R10为本次默认值；原有organizer参数名称不变，新增organizer_transition_width、organizer_transition_radius可编辑。此轮只切低部分高侧外壁，不增加内腔材料，右内胆在斜坡处露出更多。
left_insert外包络93.368×80×87，位置(-59.816,16.5,3)；right_insert外包络118.832×80×142，位置(47.084,16.5,3)。各内胆壁底3、15°斜口，最高点90/145。本次两内胆形状及刚体位置保持不变。前后及外侧间隙0.5 mm、内胆间0.8 mm。平台处口沿露出约13 mm，过渡区露出量更大。
left_drop_in与right_drop_in为free实现：外底座内底z=3承托，内胆内部底z=6；无压配、卡扣或螺丝，无材料穿透。外壁无上方钩挂或侧向倒扣，内胆沿+Z独立取出。前壁限制前滑，两条接口已处理。无外购件和PCB。
左前两格42.184×35.5，后宽格87.368×35.5。右前前三格28.611×22.667、窄格18×22.667、中后排各两格54.916×22.667，内角R3。装配尺寸调整须同步核对内胆尺寸/位置；不自动缩放。米白颗粒质感由材料体现。

## Acceptance
前、后高低交界都呈平台—圆弧—直斜面—圆弧—平台，无原直角跳变；R0.8口沿连续。三件有效实体、无互穿，装配220×120×145，左右最高90/145，左3右8格，后部共用腔无左右隔板，前托盘净深30。前后/外侧间隙0.5、内胆间0.8，底面零距离承托。最窄格≥12、左宽格≥70×25。检查整体及隔离外托座前后视图，导出三个独立对象的STEP。

## Making and assembly
默认PLA FDM。三个零件分别底面朝下打印，不能按STEP装配位置一起切片；每件都有平底和开口向上。未指定打印机、层高、支撑、温度或附着方式，本次不交付G-code。外托座占地220×120，还须为平台边距、裙边留余量。没有螺丝、胶粘或插扣装配顺序：托座置桌面，两内胆分别从上方放入后侧共用腔；取出时抓露出的口沿，沿+Z上提。可以独立清理内胆并擦拭整个外底座。
新增前壁限制前滑，仍没有向上锁止；搬运必须托住底座，不可抓内胆提起整套。0.5 mm间隙为默认设计值，实物松紧、底翘和装满稳定性仍需样件。底部0.4倒角用于缓和接触边，尚无实测过紧或拆装记录。斜坡是竖直外壁的上轮廓，不是伸入内腔的悬空平台。
