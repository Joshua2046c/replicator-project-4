# 三件式套层桌面笔筒

## Design intent
保留阶梯轮廓、15°前倾斜口、左右独立取出内胆；按user_front_wall_reference（product/references/uploads/20260923T105511576Z-1-mark.png）补齐内胆前方阶梯外壁。前外壁与原侧后壁及底板连成一件，后部容纳两内胆的共用腔不加左右隔板。原始风格、斜口和可拆参考分别为user_style_reference、user_slope_reference、user_removable_reference。整体220×120×145 mm，左最高90、右145。

## Geometry and interfaces
原点外底座底面中心，X右Y后Z上。organizer外包络220×120×133，底厚3、壁厚3，前托盘沿高15，左右后壁最高78/133。阶梯前壁外面y=-27、内面y=-24，顶沿衔接15°侧壁。前浅托盘净深30，后部共用腔214×81 mm；只有前壁将托盘和后腔分开，不做左右分格。外平面R5、内R3、顶沿R0.8、底边倒角0.4。
left_insert外包络93.368×80×87，位置(-59.816,16.5,3)；right_insert外包络118.832×80×142，位置(47.084,16.5,3)。为保留原定30 mm浅托盘及120 mm整体深度，两个内胆默认深度由83.5改为80，后面位置不变，前端退后3.5。各内胆壁底3、15°斜口，最高点90/145不变。前后及外侧间隙0.5 mm、内胆间0.8 mm，露出口沿约13 mm便于取出。
left_drop_in与right_drop_in为free实现：外底座内底z=3承托，内胆内部底z=6；没有材料重叠或压配，没有卡扣螺丝，无向上锁止。外壁与内胆均无上方钩挂、顶盖或侧向倒扣，沿+Z独立取出。新增前壁限制前滑，两条接口均已处理。无标准件、外购件、PCB。
左前两格42.184×35.5，后宽格87.368×35.5。右前前三格28.611×22.667、窄格18×22.667，中后排各两格54.916×22.667。水平包络尺寸，角R3。
参数保留原有名称；organizer_tray_clear_depth继续控制实际30 mm托盘深度；新增organizer_front_clearance=0.5定义目标前隙。对象深度和位置独立可编辑，改套装尺寸时需同步核对两内胆尺寸/位置，不自动缩放。米白颗粒质感留给材料而不建模微粒。

## Acceptance
3个有效实体，装配220×120×145，左右最高90/145，左3右8格。前外壁补齐，与外托座一体；后部共用腔无左右隔板，前托盘净深30。前后/外侧间隙0.5、内胆之间0.8，各件底厚壁厚3，无装配穿透，承托底面零距离接触。最窄格≥12、左宽格≥70×25。视觉检查整体及隔离外底座，导出含三个独立对象的STEP。

## Making and assembly
默认PLA FDM。三个零件分别底面朝下打印，不能按STEP装配位置一起切片；每件都有平底和开口向上。未指定打印机、层高、支撑、温度或附着方式，本次不交付G-code。外托座占地220×120，还须为平台边距、裙边留余量。没有螺丝、胶粘或插扣装配顺序：托座置桌面，两内胆分别从上方放入后侧共用腔；取出时抓露出的口沿，沿+Z上提。可以独立清理内胆并擦拭整个外底座。
新增前壁限制前滑，仍没有向上锁止；搬运必须托住底座，不可抓内胆提起整套。0.5 mm间隙为默认设计值，实物松紧、底翘和装满稳定性仍需样件。底部0.4倒角用于缓和接触边，尚无实测过紧或拆装记录。
