# 阶梯分格桌面笔筒

## Design intent
按用户参考图 user_style_reference（product/references/uploads/20260922T130920718Z-1-image.png）制作一体式圆角笔筒；左低右高，前方双浅托盘。用户选定220×120×145 mm包络、左侧最高点90 mm。根据 user_slope_reference（product/references/uploads/20260922T135609685Z-1-mark.png）的红圈，左右深格顶部外壁及隔板改为相对水平面15°、朝前方托盘降低的斜面；保留55 mm左右高低差，托盘不变。

## Geometry and interfaces
一个发布对象 organizer，一个连通实体，无装配接口、外购零件或PCB。X向右、Y向后、Z向上，底面中心原点。直壁/隔板2.4 mm、底板3 mm，外轮廓平面R5、内部平面R3、口沿R0.8，底部外沿0.4 mm倒角。11个深格及2个前托盘，所有腔底z=3；托盘边沿z=15。左右斜口经R0.8圆滑后的最高点分别90和145 mm。
斜面方程z=H+0.2425802983+tan(15°)*(y-60)，H为90或145；0.24258为保留后部圆角最高点所需的导出补偿，不是新增独立尺寸。前侧外壁y=-27.6处理论斜面约66.77/121.77 mm，圆滑边缘略低。参数organizer_forward_slope_deg控制角度。
左右区域按可用宽度44:56分配。左前2格45.616×40.2，左后宽格93.632×40.2；右前3格31.323×26及最右18×26窄格，中后各2格58.384×26；前托盘93.632×30和119.168×30。净尺寸为XY圆角切线包络，不代表角部或沿斜面也有同样空间。详情见product/constraints.json。
主要尺寸、壁底厚、两区比例、行分配、分隔位置、窄槽、斜角及圆角在源代码中公开为参数。平面圆角处局部增厚，口沿圆角有自然收薄。米白颗粒表面不作为几何颗粒建模；预览颜色仅用于辨识几何。

## Acceptance
检查侧视两层均朝前下降15°，俯视13个开口、正面左右阶梯和斜视外观；检查220×120×145包络、单一有效实体、3 mm封底、2.4 mm标称直壁。最窄深格≥12 mm，左宽格≥70×25 mm。托盘保持水平。以精确最终构建导出STEP；不交付G-code。打印后的稳定性和手感需样件验证。

## Making and assembly
拟用PLA一体FDM原型，z=0平底贴平台、开口向上。没有螺丝、胶粘、插装件或拆装顺序。竖直开口分格不设置顶盖和水平桥；实际支撑、层高、耗材温度及平台附着方式由真实打印机的切片检查决定，本轮未配置。底部0.4 mm倒角减轻接触边锐感，主体保留平底。平台需要容纳220×120 mm占地及145 mm高度，另留边界/裙边空间；未指定机器，不宣称适配任何机型。深窄格需从上方用细刷清理；未打印，尚无装满文具后的稳定性或手感实测。
