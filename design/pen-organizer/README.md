# 三件式套层桌面笔筒

## Design intent
依据user_style_reference的阶梯轮廓、user_slope_reference的前倾15°斜口，以及user_removable_reference（product/references/uploads/20260922T140517974Z-1-mark.png）圈定的左右可取出内胆。用户要求外底座一体不分格，并允许加厚。当前为三件：organizer整体外托座、left_insert左三格内胆、right_insert右八格内胆。整体220×120×145 mm，左最高90、右最高145，口沿前低后高15°。

## Geometry and interfaces
X右、Y后、Z上；底座中心原点。外底座220×120×133，前沿15，左后支撑最高78，右后支撑最高133；单一214×114内腔，无隔板、前挡块或分格。3 mm壁底、平面外R5内R3、口沿R0.8及底边倒角0.4。
左内胆外包络93.368×83.5×87，位置(-59.816,14.75,3)。右内胆118.832×83.5×142，位置(47.084,14.75,3)。各自壁底3 mm，斜口R0.8。各件在自身z=0底面建模，以Workbench刚体定位装配。默认间隙外侧及背侧0.5，内胆间0.8。内胆后沿比支撑最高点高12 mm（同Y处约12.94），供抓取；从前方也可抓握内胆。
两条接口left_drop_in及right_drop_in均为free实现：内胆底面与外底座内底z=3接触承托；不是压配、没有卡扣或紧固件，不产生材料重叠；直接向+Z提起。各内胆为恒定XY外包络，底面小倒角，无侧向钩挂或顶盖限制移出。连接清单在product/constraints.json中，两条均已落实。无标准件、无采购件、无PCB。
左前两格42.184×37.25、后宽格87.368×37.25；右前前三格28.611×23.833、窄格18×23.833、中后各两格54.916×23.833。均为水平投影包络，内角R3。前部为净深30的单连通浅托盘。各内胆内部底面装配z=6（内外双层底），不是旧版z=3。
所有新增零件有对象前缀参数；沿用的旧参数名保留在相应零件。外底座尺寸、内胆尺寸和刚体位置可独立改动，但改动装配尺寸后必须重新核对间隙，不能假设三件自动同步缩放。米白颗粒质感不在实体中建模。

## Acceptance
装配220×120×145、左右最高90/145；三件各一个有效实体，总3实体；无互穿。底座单连续内腔；左3格右8格；侧后间隙0.5、两内胆间0.8，底部支撑接触为有意的零距离。斜口前倾15°，壁底厚3。最小格宽≥12，左宽格≥70×25。检查整体、隔离底座及内胆底面视图，输出含三个独立对象的装配STEP。

## Making and assembly
默认PLA FDM。三个零件分别底面朝下打印，不能按STEP装配位置一起切片；每件都有平底和开口向上。未指定打印机、层高、支撑、温度或附着方式，本次不交付G-code。外托座占地220×120，还须为平台边距、裙边留余量。没有螺丝、胶粘或插扣装配顺序：托座置桌面，两内胆分别从上方放入后侧；取出时抓露出的口沿，沿+Z上提。可以独立清理内胆并擦拭整个外底座。
为符合底座不分格，未加内部分隔、定位槽或前止挡：内胆可向前滑移；搬运必须托住底座，不可抓内胆提起整套。0.5 mm间隙为默认设计值，实物松紧、底翘和装满稳定性仍需样件。底部0.4倒角用于缓和接触边，尚无实测过紧或拆装记录。
